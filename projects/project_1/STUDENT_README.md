# CS676 Project 1 — Credibility Scoring

This file summarizes my implementation, results, and live deployment for Project 1.

## Live Deployment

This project is deployed as a Streamlit application on Hugging Face using Docker.

**Live App:** https://huggingface.co/spaces/halldus1/cs676-credibility-scoring

## Results

- Rules-only MAE: 0.092
- Rules-only band accuracy: 70.8%
- Rules-only worst error: 0.230
- Rules + Claude Haiku MAE: approximately 0.079
- Rules + Claude Haiku band accuracy: 87.5%
